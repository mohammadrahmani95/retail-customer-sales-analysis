# Input data

Place the original, unmodified `online_retail_I.csv` and `online_retail_II.csv` files here. Local copies are included in the delivered project folder but excluded from Git to avoid publishing data with an unverified redistribution license.

Required columns: Invoice, StockCode, Description, Quantity, InvoiceDate, Price, Customer ID, Country.

The notebook checks overlapping records, parses dates, preserves missing customer IDs, and performs all cleaning reproducibly. An original download URL and license were not supplied; obtain those from the dataset provider before redistributing the raw files.
